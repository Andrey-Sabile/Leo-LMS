# LeoLMS Teaching-Centric LMS

## Product North Star
- Deliver a web-first learning management hub that prioritizes teachers while keeping students, admins, and parents aligned.
- Centralize class operations so teachers can manage instruction, assessments, and student artifacts without leaving one workspace.

## Primary Roles
- Teachers: design and run classes, manage content, review submissions, track performance.
- Students: join assigned classes, access learning materials, submit work, sit assessments, participate in class discussions.
- Admins: oversee enrollment, roster management, schoolwide announcements, compliance reporting.
- Parents: monitor student progress, view announcements, receive teacher updates.

## Platform Scope
- Web application optimized for laptop browsers; responsive layout without mobile-first flows.
- Authentication-aware dashboards tailored per role.
- Language switcher supporting multiple locales from launch; no offline mode required.

## Core Journeys
- Teachers configure classes per subject, populate lesson plans, schedule assignments, build exams, and record attendance and grades.
- Students view their class schedule, consume resources, submit assignments, take exams, and engage in subject-specific forums.
- Admins enroll users, maintain rosters, broadcast schoolwide announcements, and audit academic activity.
- Parents access a consolidated view of their child’s classes, upcoming assignments, and teacher communications.

## Feature Modules
- Class Management: multi-class dashboard, roster view, subject tagging, timetable overview.
- Lesson Planning: reusable templates, day-by-day planning, attachment support for artifacts, lesson status tracking.
- Learning Content Delivery: file/video hosting, live session scheduling with join links, resource library organized per class.
- Assignments & Submissions: create assignments with rubrics, student upload portal, inline review workspace for teachers, submission status tracking.
- Assessment Suite: question bank with tagging, exam builder, secure exam-taking flow, automated scoring plus manual override.
- Gradebook & Reporting: grade entry grid, category weighting, progress summaries per student/class, export to CSV/PDF.
- Attendance: daily roll call, bulk status updates, attendance history with notes.
- Announcements: schoolwide broadcasts, class-level updates, optional acknowledgment tracking.
- Subject Forums & Q/A: class-scoped discussion threads, teacher pinning/highlighting, parent read-only access.
- Artifact Repository: class-linked storage for lesson materials, photos, and documents with version history.

## Teacher Workflow Emphasis
- Single class workspace combining lesson plans, assignments, exams, and gradebook controls.
- Quick actions for copying content across classes or academic terms.
- Notification center highlighting submissions to grade, attendance anomalies, and forum activity.

## Student Experience Highlights
- Timeline view of upcoming lessons, assignments, and exams across classes.
- Submission locker showing draft, submitted, and graded work.
- Contextual Q/A entry points tied to lessons or assignments.

## Admin & Parent Views
- Admin control panel for user provisioning, class creation, and enrollment auditing.
- Parent digest summarizing student workload, recent grades, and announcements with optional email alerts.

## Global Considerations
- Role-based permissions with audit trails.
- Consistent theming aligned with institutional branding options.
- Accessibility support for keyboard navigation and screen readers.

## Future Extensions
- Classroom artifact editing (whiteboards, collaborative notes).
- Deeper analytics dashboards per class, subject, and grade level.
- SIS, calendar, and storage integrations once core flows stabilize.
